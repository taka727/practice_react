# 概要
React　練習用リポジトリ兼gitとgitCLIの使い方を勉強する

## 使い方
- 練習用のディレクトリを作成してその配下にプロジェクトを作成する

## プロジェクトセットアップ方法 
- プロジェクトの作成
  - `npm create vite@least my-react-practice-app -- --template react`
- フォルダに移動して、パッケージのインストール
  - `cd my-react-practice-app`
  - `npm install`
- サーバー起動して確認
  - `npm run dev`
